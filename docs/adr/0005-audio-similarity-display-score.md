# 0005. 음악 파일 검색과 임시 유사도 표시 기준

## 상태

개발용 기준 채택 (2026-10-02 사용자 결정). 사용자용 최종 점수는 미확정.

## 결정과 근거

- 음악 파일로 검색할 때 Audio 임베딩끼리 코사인 유사도를 비교한다.
- 순위는 원본 유사도 기준이고 기본 상위 5곡을 반환한다. 아티스트별 집계는 후속 작업이다.
- 음악↔텍스트는 임시 0~0.4, 음악↔음악은 별도 임시 0~1 기준으로 0~100 표시 점수를 계산한다.
- 새 validation 24곡 276쌍의 215쌍이 0.4 이상이므로 같은 상한을 쓸 수 없다.
- 점수는 확률·장르 일치도·행사 적합도·종합 매칭 점수가 아니다.
- 한 명의 청취 평가 24개는 초기 진단이며 품질 보장이나 최종 보정의 근거가 아니다.

## 미확정 사항

한국어→영어 자동 변환의 공급자와 구현은 미정으로 보류한다. ADR 0004의 영어 입력
방향은 유지하지만 이번 작업에서 번역 기능을 선택하거나 구현하지 않는다.
최종 점수 기준, UI 표시 방식, BPM·리듬 분석, 종합 점수, 아티스트 집계,
DB 저장과 API·LLM 설명 연결은 후속 작업이다.

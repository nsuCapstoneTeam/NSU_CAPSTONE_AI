# 현재 AI 측 방향: CLAP 중심 곡 추천

## 상태와 우선순위

2026-10-05 사용자 요청에 따라 AI 측 작업 방향을 정리합니다.
팀 전체 합의·메인 SSOT 변경은 미정이며 이 문서는 기존 Accepted 결정을 확정적으로 대체하지 않습니다.
노션 회의 자료는 미정 제안으로 유지합니다. 이전 항목 평균·Spring Ranker 문서는 합의 이력입니다.

## 현재 작업 방향

- 개별 곡을 기준 음악과 비교해 CLAP 코사인 유사도 순으로 정렬합니다.
- Spring은 조건 필터링·권한 확인·ACTIVE revision 재검증·곡과 아티스트 정보 연결·결과 전달을 담당하는 방향을 제안합니다.
- 초기에는 BPM·리듬 항목 평균에 의한 종합 점수·별도 Backend Ranker를 사용하지 않는 변경안입니다.
- BPM·리듬 분석은 불가능한 기능이 아니라 별도 검증 후 도입을 결정할 보류 항목입니다.
- 추천 이유는 실제 유사도와 확인된 조건 등 검증 가능한 근거로 제공합니다.
  CLAP 점수를 특정 악기·장르·리듬의 직접적인 선정 원인이나 일치율로 해석하지 않습니다.
- 세부 음악 설명·태깅·텍스트 비교는 별도 검증이 필요하며 검증된 기능으로 표시하지 않습니다.
- 후보 간 비교 문장은 제외합니다. 기준곡·추천곡 청취 비교는 별개 기능입니다.
- 곡→아티스트 점수 집계는 하지 않습니다.

## 처리 흐름

Spring 조건 필터 → ACTIVE 후보 곡 쌍·기준 음악 전달 → AI 공통 임베딩 생성 →
CLAP 코사인 검색·정렬 → 점수·곡 식별자·검증 가능한 근거 반환 → Spring 정보 연결·화면 표시.

음악 파일·DB 검색 CLI는 구현되어 있으나 후보 revision 쌍 HTTP 검색·설명·화면은 후속 구현입니다.
API 필드·경로와 점수 정밀도는 상세 계약으로 합의합니다.

## 신뢰 확보 방안

- 기준곡·추천곡 재생 비교
- 음악 유사도 표시 의미 안내: 확률·일치율과 구분
- 실제 통과한 행사 조건·아티스트 프로필·신뢰 정보 별도 표시
- 비슷함/다름 피드백과 별도 평가 표본 청취 검증
- 모델·전처리·분석 구간 기록과 장애/결과 없음 구분

## 미정

반환 개수, 상위 비율, 최소 점수, Top10 제한 해제, 더 보기, 신규 슬롯,
추천 이유의 세부 방식·timeout·실패 표시와 팀 전체 역할 변경은 별도 협의합니다.

회의에서 판단할 근거와 목록은 [회의 자료](../협업-가이드/CLAP_RECOMMENDATION_MEETING_PROPOSAL.md)를 참고합니다.
